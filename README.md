# 🌸 Whimsy Wheel

A whimsical Python-based fortune generator that brings a little magic with every spin.

## ✨ Features

- 🎡 Random spinning animation
- 🍀 Lucky color generator
- 🔢 Lucky number generator
- 🦊 Random animal, drink, flower, dessert, and book mood
- 🌙 Magical fortune messages

## 🛠 Technologies Used

- Python

## ▶️ How to Run

1. Download/clone the repository
2. Run:

```bash
python whimsy_wheel.py
